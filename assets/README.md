# Engine Resources

The build installs these files directly in this directory:

- `woof.pk3`: Woof's built-in graphics, configuration, and other engine data.
- `odamex.wad`: Odamex's built-in fonts, graphics, sounds, and game definitions.
  It is installed when the Odamex client is built.

These files are generated from the matching engine sources. Use the copies
shipped with the native libraries. They are not playable games; put game IWADs,
including `freedoom1.wad`, `freedoom2.wad`, and `freedm.wad`, directly in
`../iwads/`.
